# Working on herdr-persist

- Read `DESIGN.md` first. It is the spec; update it when an experiment changes the plan.
- herdr-app's own reference is `~/.config/herdr-app/AGENTS.md` and
  `~/.config/herdr-app/herdr.d.ts` (regenerated by the app; don't edit). `hc schema` and
  `herdr-app commands` list the core and app APIs.
- Develop the mod in `mods/persist/` here. To try it, symlink that folder into
  `~/.config/herdr-app/mods/persist` and run `herdr-app check ~/.config/herdr-app/mods/persist`,
  then `herdr-app status` for load errors.
- The person is working in this same herdr-app while you test. Make a scratch space of
  your own for experiments. Never send keys, `terminal.show`, `pane.go` or focus changes to
  their existing spaces, tabs or panes, and never kill terminals you didn't start. Kill
  your test terminals when done.
- Don't edit the person's `~/.config/herdr-app/keys.json` or layouts without asking.
